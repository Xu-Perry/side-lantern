# SideLantern v0.1 Windows 主机端设计

## 目标

在 Windows 上安装 SideLantern 后，从桌面端启动串流主机、配对原版 Moonlight、查看当前连接和管理常用设置。Windows 主显示器是默认串流来源。用户也可以启用一个虚拟扩展屏，并将它选为串流来源。多台客户端可以同时连接并观看当前来源。

首版范围包括独立安装包、主机管理界面、后台串流服务、虚拟显示器组件、虚拟手柄支持、可选迁移和中英文界面切换。自定义 Moonlight 客户端、主机随机出码后由客户端输入、客户端直接选择副屏、主屏和副屏分别并行串流、完整连接历史和高级 Sunshine 配置均列入后续范围。

## 方案选择

| 方案 | 取舍 |
| --- | --- |
| Electron 加载 Sunshine Web UI | 可快速复用现有功能。桌面交互、菜单和页面内容继续由上游界面约束。 |
| Electron 独立界面，复用 Sunshine 原生引擎 | 已选。复用采集、编码、音频、输入和 Moonlight 协议。需要自行完成首次设置、会话状态和服务管理。 |

SideLantern 使用新的 Electron 界面。上游 Web UI 源码供 API 调用参考。日常操作和首次设置都能在桌面端完成。

## 界面及行为

| 页面 | 首版交互 |
| --- | --- |
| 串流主机 | 显示主机名、局域网地址、服务状态、当前来源和活跃设备数。服务状态包含启动中、等待连接、正在串流、正在停止、已停止和启动失败。已配对设备列表在服务停止时仍可查看最近一次成功读取的数据，并标明当前服务状态。收到原版 Moonlight 请求后显示待配对项，由用户输入客户端显示的 PIN。配对成功后刷新设备列表。设备可解除配对。这里显示串流来源。 |
| 串流设置 | 选择主显示器或已启用的虚拟副屏。主显示器是默认来源。编码器默认自动，HEVC 和 AV1 可独立选择自动或禁用，默认自动。码率上限以 Mbps 输入，默认 0，表示采用客户端请求值。主机声音默认开启。串流分辨率、帧率和目标码率在 Moonlight 设置。 |
| 虚拟显示器 | 显示组件状态，允许用户启用、关闭和修改副屏分辨率及刷新率。界面列出驱动实际支持的模式。设置默认为关闭，初次启用优先使用 1920 × 1080、60 Hz。 |
| 应用设置 | 主题为跟随系统、浅色或深色，默认跟随系统。语言可选简体中文和英文。主题和语言切换立即生效并保存。登录 Windows 时启动默认关闭，开启后登录时打开托盘并启动串流服务。可打开日志目录并查看 SideLantern、Sunshine、虚拟显示器驱动和 ViGEmBus 的组件信息。 |

Moonlight 中沿用 Windows 版 Sunshine 默认入口「桌面」和「Steam Big Picture」。导入的应用保留在 Moonlight 列表，并提供导入结果和失效路径提示。桌面端的「串流应用」页支持新增、编辑和删除。表单提供名称、启动命令、工作目录和封面路径，编辑保留原有高级配置。

有活跃连接时，单独修改来源会排队等到全部连接结束，随后首次连接使用新来源。期间加入现有串流的客户端继续观看当前来源。需要重启引擎的参数、关闭正在使用的副屏、停服务和完全退出均会影响全部当前连接，执行前显示影响并请用户确认。关闭或最小化窗口时释放界面并进入托盘，服务和连接继续运行。从托盘打开时重新创建窗口并读取主机状态。

### 国际化

- SideLantern 桌面端支持简体中文（`zh-CN`）和英文（`en`）。从「应用设置 → 语言」选择「简体中文」或「English」。首次运行按 Windows 界面语言匹配，未匹配时使用英文。手动选择保存在应用偏好中，重开时恢复。
- 切换后立即更新页面、对话框、应用提示和托盘菜单，保留当前页面及未保存的表单内容。无需重启应用或 Sunshine 服务，正在进行的串流继续运行。
- SideLantern 自有文案统一通过独立的语言资源和翻译键提供。新增界面文案时保持两种语言的键和插值参数一致，运行时缺失翻译回退到英文。设备名称、IP 地址、日志原文和 Sunshine 配置键按原值显示。
- 验收两种语言双向切换、重开后偏好恢复、较长英文文案的布局，以及串流中切换语言时连接保持。

## 组件和数据

### Windows 服务及桌面进程

- SideLantern 有独立的服务标识、安装目录、配置目录、防火墙规则和日志。串流服务按需启动，自动启动由 SideLantern 的 Windows 登录启动设置驱动。
- 有活动的桌面进程时，参考 Sunshine 的 Windows 服务机制，在当前交互式会话中启动引擎。安装阶段注册服务，并允许安装所属的 Windows 用户查询、启动和停止本应用的服务。日常 UI 以普通权限运行。服务从固定的安装目录启动受保护的程序文件，并确保由用户配置的应用以交互式用户权限启动。
- 正常退出时，桌面端请求服务停止，验证引擎退出后结束桌面进程。服务验证桌面进程的归属并监视其存活，强退、崩溃或注销时也清理串流引擎。服务没有有效桌面进程时停止，恢复策略也遵循这一规则。服务启动、失败、退出和会话切换记录入日志。
- 桌面端单实例。打开新的 SideLantern 进程时默认启动服务，再读取引擎及配置的真实状态。手动停止在本次运行期间有效，从托盘恢复窗口时维持停止状态。串流服务启动失败时保留界面，提供原因、重试和日志入口。

### 首次启动和管理接口

- 首次启动创建独立的管理凭据及主机身份材料，再启动串流引擎并进入首页。开发阶段验证采用本机受保护的初始化流程。管理凭据由应用保管，设置目录和密钥访问限定为本应用运行所需的 Windows 帐号。
- Electron 主进程访问同机 Sunshine 管理接口，验证对应实例的证书，保留已有认证和 CSRF 校验。渲染层仅通过有限的 IPC 接口读取状态、提交配置和配对。管理接口采用仅允许本机管理的配置。串流和发现服务继续面向客户端。
- 配置表单仅修改自己管理的字段，保存时保留同一配置中的其他值。码率以 Mbps 显示，转换为 Sunshine 配置所用的 Kbps。写入失败时保留最后一次可用配置，并显示可恢复的错误。
- 配对设备列表复用现有接口。补一个只读管理接口，按会话返回设备标识、已认证的设备名称和实际采集来源，用它计算活跃设备数。相同设备开启多个会话时，设备数按标识去重。服务不可达时，当前连接显示为不可用，配对记录可标明为缓存。会话结束后清除活跃标记。
- 配对请求与具体挂起的配对会话关联，显示请求来源并支持取消。设备解除配对需确认，并验证对应设备的访问被撤销。

### 虚拟显示器和手柄

- 采用 Windows 支持的虚拟显示器驱动。正式打包前验证发行来源、签名、再分发条件、安装和卸载方式，以及枚举、启停和模式切换接口。驱动及配套服务随正式安装包部署，优先复用兼容的已安装组件。
- 虚拟屏创建为扩展显示器。使用 Windows 返回的实际设备标识选择 Sunshine 的输出。显示器不存在、驱动不可用或设备标识失效时，显示原因并回到主显示器。退出、强退或停服务后移除 SideLantern 创建的虚拟屏，同时保存启用偏好和模式，下次启动时按偏好恢复。已存在的其他显示设备保持原样。
- ViGEmBus 安装选项默认勾选，可以取消。检测到兼容版本时直接复用。首版验证 Xbox 360 或 DualShock 4 虚拟手柄。驱动不可用时显示手柄状态，保留该环境已有的键鼠和音视频能力。

## 安装、迁移和本机测试

### 首次试用

测试前检查原 Sunshine 的服务和端口。只在需要使用同一组串流端口时临时停止原 Sunshine，保留其程序、安装记录、开机启动配置、主机身份和 Moonlight 配对。SideLantern 使用自己的测试安装位置和配置。测试结束后停止 SideLantern 的服务。如果原 Sunshine 是本次测试停止的，则恢复到测试前的运行状态，并检查它仍可连接。

测试阶段使用独立主机标识，原 Moonlight 条目继续关联原 Sunshine。测试版复用本机兼容驱动。在已有系统上变更驱动前，先核对当前驱动和替换影响。

### 正式替换

正式切换使用单独的用户操作流程。可在卸载原 Sunshine 前生成本地迁移备份，安装 SideLantern 后选择导入。配对迁移保留主机身份、证书、私钥和配对记录，应用迁移保留应用条目及相关素材，并报告失效路径。迁移凭据按新应用的首次启动流程处理。编码、网络等高级参数使用首版默认值。

安装、升级及卸载只修改由 SideLantern 拥有的资源。共享驱动或原先已安装的系统组件由原安装方管理。升级保留 SideLantern 自己的配置和配对。安装和导入遇到失败时保留原数据，并说明可以重试的步骤。

## 验收

1. 全新安装后可进入桌面首页。普通用户能启动和停止 SideLantern 服务。启动、端口占用、驱动缺失和认证失败均有可操作的反馈。
2. 原版 Moonlight 能发起 PIN 配对、启动桌面串流。主屏的画面、声音和输入可用。检测到兼容 ViGEmBus 时，至少一种支持的虚拟手柄可以使用。
3. 启用虚拟显示器后，Windows 识别为扩展屏。选用虚拟副屏后，Moonlight 看到该屏。修改模式、关闭副屏和回到主屏时，Windows 的显示拓扑与界面状态一致。
4. 两台设备同时串流同一来源时，首页显示两台活跃设备。断开一台后，另一台继续串流，活跃标记随会话更新。正在串流时修改来源，等全部连接结束后，新连接才使用新来源。解除配对后，对应设备失去访问权限。
5. 关闭或最小化窗口后串流继续。从托盘退出或结束 Electron 主进程后，引擎停止且本应用创建的虚拟屏移除。重启时按照已保存的设置恢复虚拟屏。退出期间发生错误时，界面或日志保留真实状态。
6. 三种主题切换即时生效，重开保留偏好。开机启动设置会随登录生效，打开日志目录可定位实际日志。
7. 在已安装 Sunshine 的机器上试用后，原服务可恢复，原配对和应用仍可用。单独验证正式安装的干净启动、升级以及可选配对和应用迁移。
